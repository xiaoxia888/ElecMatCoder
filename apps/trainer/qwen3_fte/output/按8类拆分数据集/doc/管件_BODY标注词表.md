# 管件种类数据集标注规范 V3.1

> 状态：已固定  
> 生效日期：2026-08-06  
> 适用范围：管件种类一阶段结构化提取训练集、验证集和专项对比数据集

## 1. 使用原则

`BODY`只表示管件的标准产品类型。标注时先识别基础产品，再叠加会改变产品类型的结构特征，最后从本词表选择标准词，禁止自行创造新名称。

判定优先级：完整产品名称 > 公认英文名称或缩写 > 结构特征与基础产品组合 > 通用产品名称。

以下内容不进入`BODY`：材质、尺寸、壁厚、压力、标准、制造工艺，以及没有形成独立产品类型的普通连接方式。

管件采用字段正交化标注：`BODY`保留核心产品结构，连接形式统一写入`CONN`。普通`BW/BE/PE`是默认端部，不写入`CONN`；`SW、NPT、FNPT、THD、GRV`等需要编码的连接形式写入`CONN`。不得因为出现`SW/NPT/THD`而创建“承插焊管帽、螺纹弯头、螺纹三通”等组合BODY。

法兰属于独立产品体系，`承插焊法兰、螺纹法兰、带颈对焊法兰`等连接词同时定义其标准结构型式，因此保留在法兰`BODY`中；该例外不得反向套用到普通管件。

### 1.1 字段职责

| 字段 | 只表达什么 | 不得表达什么 |
|---|---|---|
| `BODY` | 产品结构身份 | 普通连接形式、制造工艺、尺寸、材质、标准 |
| `GEOMETRY.ANGLE` | 原文明示角度 | 英制尺寸、管径、标准号、默认角度 |
| `GEOMETRY.RADIUS` | 原文明示相对或绝对弯曲半径 | 壁厚、管径、标准号 |
| `FLANGE_STYLE` | 管件自身的法兰端结构 | 配套法兰、法兰标准、密封面 |
| `MANU` | 原文明示的产品制造工艺 | 现场焊接方法、产品名称中的`WELD`、材质牌号后缀 |
| `CONN` | 需要独立编码的明示连接形式 | 默认`BW/BE/PE`、组合端部形式、施工工艺 |

### 1.2 冲突处理优先级

1. 原文明示的完整产品名称优先识别语义，但输出仍按字段拆分，例如`SOCKOLET`归一为`BODY=支管台、CONN=["SW"]`。
2. 产品结构身份优先于连接形式，例如`45° SOCKOLET`的`BODY`是`斜支管台`，`SW`另写入`CONN`。
3. 明确设计选型优先于施工或工艺执行信息。例如材料选型段写`FNPT`，施工段写“承插焊”时，仅标`CONN=["FNPT"]`。
4. 具体标签优先于泛化标签，例如`FNPT`优先于`NPT/THD`，`SAW`优先于`WELDED`。
5. 无法判断时留空或进入人工审核，禁止通过标准、材质、尺寸和常识补标签。

### 1.3 跨类别固定判定表

同一个连接词在不同产品体系中的作用不同，必须先判断产品类别，再按下表拆分字段：

| 原文语义 | CATEGORY | BODY | CONN | 其他字段 |
|---|---|---|---|---|
| `NPT CAP`、螺纹管帽 | 管件 | 管帽 | `NPT`或原文最具体螺纹值 | - |
| `SW ELBOW`、承插弯头 | 管件 | 弯头 | `SW` | 角度和半径分别写入`GEOMETRY` |
| `SOCKOLET`、承插焊支管台 | 管件 | 支管台 | `SW` | - |
| `WELDOLET`、对焊支管台 | 管件 | 支管台 | `[]` | `BW/BE`不写入`CONN` |
| `SOCKET WELD FLANGE` | 法兰 | 承插焊法兰 | `SW` | 密封面写入`SEAL` |
| `NPT/SCREWED FLANGE` | 法兰 | 螺纹法兰 | `NPT/SCRD` | 保留原文最具体制式 |
| `WN FLANGE` | 法兰 | 带颈对焊法兰 | `[]` | `WN/BW`不写入`CONN` |

因此，`SW`在管件中不得改写产品主体，在法兰中则是“标准法兰结构型式 + 连接编码证据”，必须同时体现在`BODY`和`CONN`中。

### 1.4 BODY中连接词的有限例外

原则上连接形式只写入`CONN`。仅当连接词与端口数量或产品标准结构不可分割时，才允许保留在`BODY`中。当前例外为闭合清单：

| 例外产品 | BODY保留原因 | CONN处理 |
|---|---|---|
| 单头/双头螺纹短节 | “单头/双头”表示螺纹端数量，当前没有独立端数字段 | 仅保留`NPT/FNPT/MNPT`等具体制式；泛称螺纹不重复追加`THD` |
| 单/双承口、单/双螺口管箍 | “承口/螺口 + 端口数量”是产品结构名称 | 只有原文另外明示`SW/NPT`等时才写入`CONN` |
| 承插焊/螺纹/带颈对焊法兰 | 属于法兰标准结构型式 | 按《法兰种类数据集标注规范》处理，不套用普通管件规则 |

除上表外，不得新增“承插焊管帽、螺纹管帽、承插焊弯头、螺纹三通、承插焊支管台”等将普通连接形式拼入`BODY`的新标签。

## 2. 弯头与弯管

| 标准 BODY | 典型表达 | 判定条件 |
|---|---|---|
| 弯头 | ELBOW、ELB、弯头 | 未明确异径或夹套 |
| 异径弯头 | REDUCING ELBOW、异径弯头 | 明确异径 |
| BEND | BEND、Bend、弯管 | 产品明确为弯管而非弯头 |
| 夹套弯头 | JACKET ELBOW、夹套弯头 | 明确夹套结构 |

角度和半径不拼入`BODY`，分别写入`GEOMETRY.ANGLE`和`GEOMETRY.RADIUS`。

| Y型三通 | Y-TEE、Y型三通，未说明等径或异径 |
| Y型等径三通 | Y EQUAL TEE、Y型等径三通 |
| Y型异径三通 | Y REDUCING TEE、Y型异径三通 |
| 仪表三通 | INSTRUMENT TEE、仪表三通 |

| 剖分异径三通 | SPLIT REDUCING TEE、剖切/剖分异径三通 |
| 等径四通 | EQUAL CROSS、同径/等径四通 |
| 异径四通 | REDUCING CROSS、异径四通 |
| 剖分等径四通 | SPLIT EQUAL CROSS、剖切/剖分同径四通 |

| 夹套异径三通 | JACKET REDUCING TEE、夹套异径三通 |
| 夹套剖分等径三通 | 夹套管剖分三通、JACKET SPLIT EQUAL TEE |
| 夹套剖分异径三通 | 夹套剖分异径三通、JACKET SPLIT REDUCING TEE |
| 夹套剖分三通 | 夹套剖分三通、JACKET SPLIT TEE，未说明等径或异径 |

“剖分”必须有明确结构证据，例如`剖分、剖切、纵向剖分、SPLIT、SPLIT IN 2 HALVES、LONGITUDINALLY SPLIT`。仅有“成对包装、配对供货”不能推导为剖分。夹套、等径/异径和剖分同时出现时必须组合为对应的夹套剖分标准词，不能丢失任一结构特征。

三通主体和角度按以下规则组合标注：

- 普通三通未明示角度时，业务默认角度为90度；原文未写角度时`GEOMETRY.ANGLE`仍留空，不在一阶段补默认值。
- 斜三通和Y型三通未明示角度时，业务默认角度为45度；原文未写角度时`GEOMETRY.ANGLE`同样留空。
- 普通三通明示非90度角度时，归一为斜三通系列。例如`45° TEE`标为`斜三通`，`45° EQUAL/STRAIGHT TEE`标为`等径斜三通`，`45° REDUCING TEE`标为`异径斜三通`，角度均按原文写入`GEOMETRY.ANGLE`。
- 原文明示`LATERAL/斜三通`时进入斜三通系列；同时明示`EQUAL/STRAIGHT/等径/同径`时标为`等径斜三通`，明示`REDUCING/RED./异径`时标为`异径斜三通`，否则标为`斜三通`。
- Y型三通始终保持Y型主体，`Y LATERAL TEE/斜Y型三通`也归入Y型三通系列。明示等径时标为`Y型等径三通`，明示异径时标为`Y型异径三通`，否则标为`Y型三通`；不因45度等非90度角度改成普通斜三通。
- 等径/异径只根据原文的明确名称或公认缩写标注，禁止根据主管、支管尺寸是否相同推导。

`SW/THD/NPT`等端部方式不改变普通三通、四通的`BODY`，只写入`CONN`。

## 4. 异径管、接头与短节

| 产品族 | 未说明同偏心 | 同心 | 偏心 |
|---|---|---|---|
| 异径管 | 异径管 | 同心异径管 | 偏心异径管 |
| 异径管接头 | 异径管接头 | 同心异径管接头 | 偏心异径管接头 |
| 异径管箍 | 异径管箍 | 同心异径管箍 | 偏心异径管箍 |
| 异径短节 | 异径短节 | 同心异径短节 | 偏心异径短节 |

同心证据：`CON`作为独立缩写、`CONC`、`CONCENTRIC`、`R(C)`、`RC`、同心。

偏心证据：`ECC`、`ECCENTRIC`、`R(E)`、`RE`、偏心。

`SWAGE NIPPLE, CON`标为`同心异径短节`；`SWAGE NIPPLE, ECC`标为`偏心异径短节`；没有同偏心证据时标为`异径短节`。`SWAGE`中的`SW`不得识别为承插焊。

`异径接头`与`异径管接头`是同一种产品，统一使用`异径管接头`；`同心异径接头`统一为`同心异径管接头`；`偏心异径接头`统一为`偏心异径管接头`。

夹套同心异径管使用独立标准词`夹套同心异径管`。

## 5. 支管台

### 5.1 标注模型

支管台描述同时包含两个维度：

- `BODY`保留产品结构身份，例如普通支管台、短管支管台、弯头支管台和斜支管台。
- `CONN`保留支管端连接形式，例如`SW、FNPT、MNPT`。

连接形式不再创建`对焊支管台、承插焊支管台、螺纹支管台`三个BODY。`WELDOLET、SOCKOLET、THREDOLET`都属于普通支管台，分别通过`CONN=[]、["SW"]、具体螺纹值`表达端部区别。短管、弯头、斜向、扫掠、轻型、插入式和法兰结构仍属于独立结构身份，保留在`BODY`中。

原文明确写“短管支管台;SW”时，必须标为`BODY=短管支管台，CONN=["SW"]`，不得因`SW`丢失短管结构身份。

### 5.2 标准BODY

| 标准 BODY | 典型表达 | CONN约束 |
|---|---|---|
| 支管台 | OLET、WELDOLET、SOCKOLET、THREDOLET、普通支管台、对焊/承插焊/螺纹支管台 | 按原文端部证据标注；BW/BE为空 |
| 弯头支管台 | ELBOLET、弯头支管台、对焊弯头支管台 | 按原文明确信息标注；BW/BE不进入CONN |
| 斜支管台 | LATROLET、斜支管台、45°对焊斜支管台 | 按原文明确信息标注；角度另写入GEOMETRY.ANGLE |
| 短管支管台 | NIPOLET、短管支管台 | SW、FNPT等端部形式写入CONN，不改变BODY |
| 扫掠式支管台 | SWEEPOLET、SWEEP OLET、扫掠式支管台、扫头支管台 | 保留独立BODY；BW/B.W.不改变产品种类 |
| 轻型支管台 | LIGHT WEIGHT OLET、LIGHT-WEIGHT OLET、LIGHT WEIGHT BW OLET、轻型支管台 | 保留独立BODY；中间的BW只表示对焊端，不改变产品种类 |
| 法兰支管台 | WELDOFLANGE、NIPOFLANGE、FLANGOLET、明确的法兰支管台 | 通常`FLANGE_STYLE=FLANGED`；不得仅因出现法兰标准推导 |
| 插入式支管台 | INSERT WELDOLET、明确等价的插入式支管台 | 当前属于待确认类型，确认前进入人工审核 |

当前数据版本统一使用`扫掠式支管台`和`轻型支管台`两个中文标准BODY，英文产品名只作为原文识别证据，不再直接作为BODY输出。

### 5.3 普通OLET的端部判定

普通`OLET/支管台`及仅由连接形式区分的`WELDOLET/SOCKOLET/THREDOLET`按以下规则拆分：

| 端部证据 | BODY | CONN |
|---|---|---|
| 无端部证据 | 支管台 | `[]` |
| WELDOLET、WOL、BW、BE、BUTT WELD | 支管台 | `[]` |
| SOCKOLET、SOL、SW、SOCKET WELD | 支管台 | `["SW"]` |
| FNPT、Female NPT | 支管台 | `["FNPT"]` |
| MNPT、Male NPT | 支管台 | `["MNPT"]` |
| THREDOLET、NPT、NPTF、SCRD、THD等 | 支管台 | 保留原文最具体值；只有THREDOLET而无制式时标`THD` |

`SOCKET OLET/SOCKOLET`整体已经提供承插焊证据，即使没有独立`SW`也必须标为`BODY=支管台，CONN=["SW"]`。`FNPTOLET`整体标为`BODY=支管台，CONN=["FNPT"]`。

显式产品名称优先于泛化端部信息，例如`NIPOLET;SW`仍是短管支管台，`SWEEPOLET;BW`仍是扫掠式支管台。如果显式产品名称与端部语义真正冲突，例如`WELDOLET;SW`或`SOCKOLET;BW`，不得静默覆盖其中一个字段，应转入人工审核。

`BW/BE`不写入`CONN`，也不推导`MANU=WELDED`。支管台中的`FORGED/锻制`同样不进入当前`MANU`。

`LIGHT WEIGHT BW OLET`标为`BODY=轻型支管台`。这里的`BW`是轻型支管台的端部方式，不创建“轻型对焊支管台”新BODY，也不写入`CONN`。

### 5.4 角度与连接同时出现

支管台同时出现结构角度和端部形式时，两者分别进入对应字段，不把多个维度拼成新`BODY`：

| 原文 | BODY | ANGLE | CONN | MANU |
|---|---|---|---|---|
| `45° WELDOLET`、`WOL-45`、`对焊45°支管台` | 斜支管台 | `45` | `[]` | `[]` |
| `45° SOCKOLET`、`承插焊45°支管台` | 斜支管台 | `45` | `["SW"]` | `[]` |
| `45° THREDOLET` | 斜支管台 | `45` | 原文最具体的螺纹值 | `[]` |
| 普通`WELDOLET` | 支管台 | 空 | `[]` | `[]` |
| 普通`SOCKOLET` | 支管台 | 空 | `["SW"]` | `[]` |
| 普通`THREDOLET` | 支管台 | 空 | 原文最具体的螺纹值 | `[]` |

`WELDOLET`中的`WELD`和`FORGED/锻制`都不属于当前`MANU`。`45° WELDOLET`不得同时标成“对焊支管台”和“斜支管台”；结构角度出现后统一由`斜支管台 + ANGLE=45`表达。

### 5.5 疑问词与分类边界

- `SMLSOLET`不能直接判为对焊支管台。`SMLS`只表示制造方式，应写入`MANU`；剩余`OLET`按普通支管台规则处理。原文没有端部证据时标为`支管台`。
- `嵌入式支管台`不能仅因出现45°就自动标为斜支管台。只有确认它在当前项目中等同`INSERT WELDOLET`后，才统一标为`插入式支管台`；确认前进入人工审核。
- `Boss/Bosset`不自动等同Sockolet。`Boss Type`明确修饰半管接头时保持`半管接头`；只有项目编码明确把Boss作为独立产品时才使用`BODY=Boss`。
- `WELDOFLANGE/NIPOFLANGE/FLANGOLET`只有原文明示时才能标为`法兰支管台`。只出现`ASME B16.5`、法兰压力等级或配套法兰，不构成法兰支管台证据。
- 当前训练集没有法兰支管台真实样本，不得为补齐类别而虚构训练数据。
- `加强管嘴、加强管接头、补强板开口焊、半管接头`是相邻产品，不因具有支管功能并入支管台系列。

## 6. 管箍与管接头

标准词：`管箍、FULL COUPLING、COUPLING COLLAR、单口管箍、双口管箍、单承口管箍、双承口管箍、单螺口管箍、双螺口管箍、双承口异径管箍、双螺口同径管箍、双螺口异径管箍、单头管箍、双头管箍、等径双口管箍、异径双口管箍、异径双头管箍、同径双口管箍、同心管箍、同心等径管箍、同心异径管箍、同心双口管箍、同心异径双口管箍、偏心管箍、偏心异径管箍、偏心双口管箍、偏心异径双口管箍、管接头、半管接头、异径管接头、同心异径管接头、偏心异径管接头、快速接头、活接头、卡箍接头`。

| 别名 | 标准 BODY |
|---|---|
| COUPLING | 管箍 |
| FULL COUPLING | FULL COUPLING |
| HALF COUPLING | 半管接头 |
| QUICK RELEASE COUPLING | 快速接头 |
| UNION | 活接头 |
| COUPLING COLLAR | COUPLING COLLAR |

等径、异径、同心、偏心、单口、双口只有在原文明示时才加入`BODY`，不能仅根据尺寸数量猜测。

`偏心等径管箍`同时表达偏心和等径，结构语义矛盾，不属于允许的标准`BODY`。遇到该类原始描述时标记为冲突数据并人工复核，不得用于训练。

管箍口型遵循“原文名称优先”规则，不将承口或螺口折叠成普通单口、双口：

| 单口管箍 | 单口管箍 | 按独立连接信息标注 |
| 双口管箍 | 双口管箍 | 按独立连接信息标注 |
| 单承口管箍 | 单承口管箍 | 原文明示`SW`时标注`["SW"]`，否则`[]` |
| Single Socket Pipe Coupling | 单承口管箍 | 原文明示`SW`时标注`["SW"]`，否则`[]` |
| 双承口管箍 | 双承口管箍 | `[]` |
| 单螺口管箍 | 单螺口管箍 | `[]` |
| 双螺口管箍 | 双螺口管箍 | `[]` |
| 双承口异径管箍 | 双承口异径管箍 | `[]` |
| 双螺口同径管箍 | 双螺口同径管箍 | `[]` |
| 双螺口异径管箍 | 双螺口异径管箍 | `[]` |

该规则只在产品名称本身明确出现“承口”或“螺口”时生效。承口属性进入`BODY`不代表忽略原文独立的连接信息：单承口管箍或`Single Socket Pipe Coupling`如果同时明示`SW`，`CONN`仍标注`SW`；未明示则为空。产品名称仅为单口/双口管箍时，不根据后续`SW/NPT/FNPT`反向改写`BODY`。

## 8. 其他管件与分类边界

标准词：`仪表三通、金属软管、波纹金属软管、波纹非金属软管`。

### 8.1 相邻产品不得降级

| 原文明示产品 | 固定 BODY | 禁止降级为 |
|---|---|---|
| 加强管接头、REINFORCED PIPE CONNECTOR | 加强管接头 | 管接头、支管台 |
| 加强管嘴、加强管咀、REINFORCED NOZZLE | 加强管嘴 | 管嘴、支管台 |
| 马鞍座接头、SADDLE CONNECTION | 马鞍座接头 | 马鞍座、三通 |
| `SlipRing` | `SlipRing` | 同心异径管、异径管 |

`加强管咀`是“加强管嘴”的旧字形，训练标签统一为`加强管嘴`。产品名称只写“管嘴”时仍标`管嘴`，不得反向补“加强”。`马鞍座接头 三通`以完整产品名“马鞍座接头”为准，不因尾随“三通”改成三通系列。

### 8.2 管道盲板不进入管件数据集

本项目将管道用插板、垫环、插板垫环组件和8字盲板交由法兰类别承接，因为这些产品需要保留密封面并进入对应编码路径。该规则表示系统分类路由，不表示它们是法兰本体。

以下产品不得标为 `CATEGORY=管件`：

| 原文证据 | 应转入法兰类别的 `BODY` |
|---|---|
| `PADDLE BLANK`、`PADDLE BLIND`、`SPADE`、明确的单插板 | `插板` |
| `PADDLE SPACER`、明确的单垫环 | `垫环` |
| `BLANK AND SPACER`、`PADDLE BLANK & SPACER`、插板垫环成套供货 | `插板垫环组件` |
| `SPECTACLE BLIND`、`FIGURE 8 BLIND`、8字盲板 | `8字盲板` |
| `BLIND FLANGE`、法兰盖 | `盲板法兰` |

禁止继续使用以下旧规则：

```text
PADDLE SPACER      -> 管件/插板
BLANK AND SPACER   -> 管件/插板
插板垫环成套供货  -> 管件/插板
```

这三种标注会混淆单插板、单垫环和成套组件，而且管件输出骨架没有 `SEAL` 字段，会丢失原文中的 `FF/RF/RJ/RTJ/SERRATED`。

### 8.3 歧义词处理

- 原文只有“插板”且没有设备上下文时，结合 `ASME B16.48`、`SH/T 3425`、`HG/T 21547`、压力等级、密封面和管径判断是否属于管道盲板。
- “特殊管件插板”虽然带有“管件”字样，但如果上下文明确是管道盲板，应转入法兰类别并标为 `插板`，不能机械保留为管件。
- “阀门插板”如果实际指符合管道盲板标准、安装在法兰之间的插板，按管道盲板处理；如果明确是阀门内部闸板或阀板，则不属于本管件词表，也不进入法兰训练集。
- 普通法兰垫片、金属环垫、密封垫和 `GASKET/RING GASKET` 不得按管道盲板的 `垫环` 处理。
- 同一描述只有在明确表达插板与垫环成套或配套、且两者共享同一组规格时，才标为 `插板垫环组件`；两个独立明细项不得合并。
- 无法区分管道盲板和设备内部零件时进入人工审核，不得通过关键词强制归类。

管道盲板的完整 `BODY/SEAL` 规则以《法兰种类数据集标注规范》为准。

## 9. 其他字段约束

### 9.1 明确产品代号

以下代号只有在原文明示时才能使用其语义，不得根据相似字母猜测：

| 原文代号 | 固定标注 |
|---|---|
| `STS` | `BODY=等径三通`，`CONN=["SW"]` |
| `WTS` | `BODY=等径三通`，`MANU=["WELDED"]` |
| `S90E` | `BODY=弯头`，`ANGLE=90`，`CONN=["SW"]`；未明示半径时`RADIUS`为空 |
| `30EL/45EL/60EL/90EL` | `BODY=弯头`，角度取代号数字，`RADIUS=LR` |
| `30ES/45ES/60ES/90ES` | `BODY=弯头`，角度取代号数字，`RADIUS=SR` |
| `S30EL/S45EL/S60EL/S90EL` | 长半径承插焊弯头：`RADIUS=LR`，`CONN=["SW"]` |
| `90ESS`或`S90ES` | `BODY=弯头`，`ANGLE=90`，`RADIUS=SR`，`CONN=["SW"]` |
| `W30EL/W45EL/W60EL/W90EL` | `BODY=弯头`，角度取代号数字，`RADIUS=LR`，`MANU=["WELDED"]` |
| `GRV` | `CONN=["GRV"]` |

代号只补充其明确承载的维度。例如`S90E`不自动补`SR`，`90ES`不自动补`SW`。`EL`只有作为独立产品代号后缀时才表示长半径，普通英文单词`ELBOW`不得因包含`EL`而推导`LR`。

### CONN

允许值：`SW、THD、SCRD、NPT、NPTF、FNPT、MNPT、FTE、MTE、GRV`。数组按原文顺序去重；同一端同时出现泛化和具体螺纹时只保留最具体值。`BW/BE/PE/PBE`不进入当前`CONN`。

- `NPTF`保留为`NPTF`，不得转换为`FNPT`。
- 只有显式`FNPT`或`Female NPT`才标注为`FNPT`。
- 只有显式`MNPT`或`Male NPT`才标注为`MNPT`。
- 原文明示`SCRD`时保留为`SCRD`，不得转换为`THD`或`NPT`。
- 裸`NPT`标注为`NPT`；`THREADED/螺纹`等未提供具体制式的泛化表达，仅在`BODY`未表达螺纹语义时标注为`THD`。
- 原文明示`SW`、`SOCKET WELD`或“承插焊”时，`CONN`标注为`SW`。`SOCKOLET/SOCKET OLET/承插焊支管台`整体表达同样视为明确`SW`证据，但`BODY`统一为`支管台`。
- 单独“承口”、`Single Socket Pipe Coupling`不自动推断`SW`；`SWAGE`中的`SW`也不得识别为承插焊。
- `BLE/TSE、BLE/PSE、BLE-TSE、BLE-PSE、PLE/TSE、TBE`等组合端部形式当前不进入`CONN`，由平台正则单独处理。
- 同一产品同时出现设计选型`FNPT`和施工段“承插焊”时，只保留`FNPT`，不追加`SW`。
- 原文明示`GRV/GROOVED`时标注`GRV`；不得从沟槽材料、标准或产品外形推导。
- 辅助部件的连接不进入主体`CONN`，例如孔板法兰中`Pressure Taps 1/2'' SW`表示取压口连接，不代表法兰主体为`SW`。

### MANU

允许值：`SMLS、WELDED、EFW、ERW、HFW、SAW、SAWL、SAWH、DASW、DSAW、DSAWL、DSAWH`。具体焊接工艺优先于`WELDED`，不得同时输出；`SMLS`与焊接类工艺互斥。`FORGED/锻制/锻造`不属于当前`MANU`。

- `WELDOLET/WELD OLET`是产品名称，不据此输出`WELDED`。
- `BW/BE`是端部形式，不据此输出`WELDED`。
- 施工安装中的“焊接方法、焊口、氩电联焊、连接方式为焊接”不属于产品制造工艺。
- 材质牌号中的`-W/-WX`必须由材质模型保留，种类模型不得据此推导`WELDED`。
- `SFR、FRP、AF、BTA、SH`以及材质牌号不是允许的制造工艺。`SFR`在当前HG/T 3731样本中不进入`MANU`，`FRP`属于材质，`SH/T`中的`SH`属于标准前缀。

### GEOMETRY

`ANGLE`保留原文数值，仅去掉角度单位，不得取整；原文未出现角度时必须为空，不得根据弯头类型默认补`90`。

- 英制尺寸必须有角度语义证据才能进入`ANGLE`。`Elbow, 6"`中的`6`是尺寸，不是6度。
- 标准号、壁厚和管径不能进入`ANGLE`，例如`GB/T 12459`中的数字不能产生45度。

`RADIUS`只提取原文明示的相对或绝对弯曲半径：

- 相对半径统一为`LR、SR、1D、1.5D、3D`等；精确倍数优先于`LR/SR`。
- 独立产品代号的`EL`后缀表示`LR`，`ES`后缀表示`SR`。如果同一原文还明示`1D/1.5D/3D`等精确倍数，保留精确倍数，不改写为泛化`LR/SR`。
- 绝对半径保留数值和单位并统一大写，例如`R=102mm`标为`102MM`，`R=410.3 mm`标为`410.3MM`。
- 裸数字、管径、壁厚、标准号不得作为半径；原文未明示`R/RADIUS/半径`或受控产品代号时必须为空。
- `20`牌号不能产生`20D`，`GB/T 713; SH/T 3408; Elbow 1016x12.7`中的`1016`也不能成为半径。

### FLANGE_STYLE

管件自身带法兰端标为`FLANGED`，管件自身为松套法兰结构标为`LAP_JOINT_FLANGED`；仅提到法兰标准或配套法兰时为空。

## 10. V3.1旧标签迁移规则

历史数据中连接形式曾被拼入`BODY`。迁移时必须回看原文，按下表拆分，不能只对标签字符做无条件替换：

| 历史 BODY | V3.1 BODY | V3.1 CONN |
|---|---|---|
| 对焊支管台 | 支管台 | 原文仅有`WELDOLET/BW/BE`时为`[]` |
| 承插焊支管台 | 支管台 | 原文明示`SOCKOLET/SOL/SW/承插焊`时为`["SW"]` |
| 螺纹支管台 | 支管台 | 保留原文最具体螺纹值；只有`THREDOLET/螺纹`泛称时为`["THD"]` |
| 螺纹管帽 | 管帽 | 保留原文最具体螺纹值；只有泛称时为`["THD"]` |

迁移中如果原文同时出现互斥连接证据，先按第1.2节判断设计选型与施工信息；仍无法判断时进入人工审核，不自动迁移。V3.1生效后，新增和增强样本禁止继续使用上表历史`BODY`。
