# 尺寸壁厚磅级数据集标注规范 V2

> 状态：待审核  
> 编制日期：2026-08-11  
> 适用范围：尺寸、壁厚、长度和压力等级结构化抽取训练集、验证集及专项对比数据集

## 1. 文档目标

V2用于解决尺寸和壁厚在复杂产品中的归属问题，包括：

- 三通、四通和支管件的主管与支管。
- 异径管、异径短节等产品的两端。
- 夹套产品的内层与外层。
- 衬里产品的本体与衬层。
- 同一物理位置存在DN、OD、英寸或不同壁厚表达的情况。

V2采用“一个物理位置对应一个`ITEM`”的结构。模型负责提取原文明示值并判断归属，代码负责等价换算、冲突判断和最终编码选择。

## 2. 固定输出结构

```json
{
  "ITEMS": [
    {
      "SCOPE": "",
      "ROLE": "",
      "SIZE": [
        {
          "type": "",
          "value": ""
        }
      ],
      "THICKNESS": [
        {
          "type": "",
          "value": ""
        }
      ]
    }
  ],
  "LENGTH": "",
  "PRESSURE": ""
}
```

没有尺寸、壁厚、长度或压力信息时：

```json
{
  "ITEMS": [],
  "LENGTH": "",
  "PRESSURE": ""
}
```

固定约束：

1. 顶层只允许`ITEMS、LENGTH、PRESSURE`。
2. 每个`ITEM`只允许`SCOPE、ROLE、SIZE、THICKNESS`。
3. `SIZE`和`THICKNESS`必须是数组。
4. `LENGTH`和`PRESSURE`继续使用字符串。
5. 不增加`CANDIDATES、RAW、INDEX、STRUCTURE_FEATURES`等字段。

## 3. ITEM定义

一个`ITEM`代表一个确定的物理位置，其唯一坐标为：

```text
SCOPE + ROLE
```

同一条描述中，相同的`SCOPE + ROLE`只能出现一个`ITEM`。属于该位置的全部明示尺寸写入`SIZE`，全部明示壁厚写入`THICKNESS`。

例如同一主管位置同时出现`3\"`和`DN80`：

```json
{
  "SCOPE": "BODY",
  "ROLE": "MAIN",
  "SIZE": [
    {"type": "INCH", "value": "3"},
    {"type": "DN", "value": "80"}
  ],
  "THICKNESS": []
}
```

这两个尺寸是同一位置的两个明示表达，不需要额外定义为候选值。

## 4. SCOPE字段

`SCOPE`回答“尺寸或壁厚属于哪个物理层”。

| 值 | 含义 |
|---|---|
| `BODY` | 普通产品本体 |
| `INNER` | 夹套结构的内层部件 |
| `OUTER` | 夹套结构的外层部件 |
| `LINING` | 衬层、内衬或包覆层 |
| `UNKNOWN` | 已确认是尺寸或壁厚，但无法可靠确定物理层 |

固定规则：

1. 普通直管、法兰、弯头、三通、异径管和支管件使用`BODY`。
2. 夹套结构根据原文明示使用`INNER`和`OUTER`。
3. 衬层厚度使用`LINING`，产品本体壁厚仍使用`BODY`。
4. 不使用`INNER_PIPE/OUTER_PIPE`，因为法兰和管件也可能存在夹套结构。
5. `UNKNOWN`只用于属性已确认但物理层确实无法判断的情况。

## 5. ROLE字段

`ROLE`回答“尺寸或壁厚属于该物理层的哪个结构位置”。

| 值 | 含义 |
|---|---|
| `SINGLE` | 单一规格位置或整体位置 |
| `MAIN` | 三通、四通、支管台等产品的主管位置 |
| `BRANCH` | 三通、四通、支管台等产品的支管位置 |
| `END_A` | 两端异径结构中原文顺序的第一端 |
| `END_B` | 两端异径结构中原文顺序的第二端 |
| `UNKNOWN` | 已确认是尺寸或壁厚，但无法可靠确定结构位置 |

### 5.1 变径管件与分支管件

确定`ROLE`前，必须先判断产品拓扑，不能仅根据两个不同尺寸判断为变径件：

| 拓扑类型 | 判断标准 | ROLE | 典型产品 |
|---|---|---|---|
| 变径管件 | 只有一个连续流道和两个端口，作用是改变流道截面 | `END_A/END_B` | 同心异径管、偏心异径管、大小头、异径短节 |
| 分支管件 | 在主管上开孔或形成额外出口，存在主管流道和引出支路 | `MAIN/BRANCH` | 三通、四通、支管台、支管座、加强管嘴、半管接头、补强板加短管 |

固定判定原则：

1. `END_A/END_B`表示同一连续流道的两个端口。
2. `MAIN/BRANCH`表示主管与开孔引出的支路。
3. 异径三通虽然主管与支管尺寸不同，但拓扑仍是分支管件，必须使用`MAIN/BRANCH`。
4. 支管台、半管接头等即使描述为`DN主管×DN支管`，也不得标为`END_A/END_B`。
5. 只有两个不同尺寸、但没有足够产品或结构证据时，不得仅按数值大小推断拓扑，应进入审核。
6. 拓扑判定优先级为：分支结构明示 > 变径结构明示 > 尺寸组合形式。

固定规则：

1. 普通单规格产品使用`SINGLE`。
2. 三通、四通和支管件使用`MAIN/BRANCH`。
3. 同心异径管、偏心异径管和异径短节使用`END_A/END_B`。
4. `END_A/END_B`只表示原文顺序，不表示大端和小端。
5. 大端和小端由代码根据归一后的尺寸比较确定。
6. 原文未明示等径三通支管尺寸时，模型不得复制主管尺寸。
7. 原文明示主管与支管规格对时，两个非等价尺寸必须拆入`MAIN/BRANCH`，不得同时放入`SINGLE`。

## 6. SIZE字段

`SIZE`保存当前`SCOPE + ROLE`位置下原文明示的全部不同尺寸表达。

允许的`type`：

| type | 含义 | 示例 |
|---|---|---|
| `DN` | 公称直径 | `DN80 -> {"type":"DN","value":"80"}` |
| `OD` | 明示外径 | `Φ88.9 -> {"type":"OD","value":"88.9"}` |
| `INCH` | 英制公称尺寸 | `3\" -> {"type":"INCH","value":"3"}` |

固定规则：

1. 模型保留原文明示类型，不把`OD`或`INCH`转换为`DN`。
2. 同一位置出现不同明示表达时全部保留。
3. 相同`SCOPE + ROLE + type + value`的重复项只保留一次。
4. 数组顺序按原文首次出现顺序排列。
5. 原文没有明示某一位置的尺寸时，该位置的`SIZE`使用空数组。
6. 裸数字无法确认是尺寸时不提取；确认是尺寸但位置不明时使用`ROLE=UNKNOWN`。

## 7. THICKNESS字段

`THICKNESS`保存当前`SCOPE + ROLE`位置下原文明示的全部不同壁厚表达。

允许的`type`：

| type | 含义 | 示例 |
|---|---|---|
| `MM` | 绝对毫米壁厚 | `THK=4mm -> {"type":"MM","value":"4"}` |
| `SCHEDULE` | Schedule或标准壁厚等级 | `SCH40、STD、XS、XXS` |

Schedule沿用现有训练集归一格式：

```text
SCH40、S-40、S40 -> SCH40
SCH10S、S-10S、S10S -> SCH10S
STD -> STD
XS -> XS
XXS -> XXS
```

固定规则：

1. 同一位置同时明示Schedule和毫米壁厚时全部保留。
2. 相同`SCOPE + ROLE + type + value`的重复项只保留一次。
3. 数组顺序按原文首次出现顺序排列。
4. `MFR'S STD、MFR STD、MNF STD、ENR STD、CHENGDA STD`不是壁厚`STD`。
5. `1.0MPa`是压力表达，不得提取为`1MM`。
6. `100%RT`是检测要求，不得提取为壁厚。
7. 材质`20、20#、A105、F304`中的数字不得提取为壁厚。
8. 三通或四通只有一个壁厚且原文未明示位置时，默认归入`BODY + MAIN`；等径和异径结构使用相同口径。
9. 支管台、支管座、加强管嘴、补强板加短管等附加在主管上的支管附件，只有一个壁厚且原文未明示位置时，默认归入引出短管的`BODY + BRANCH`。
10. 衬里产品只有一个壁厚且原文未明示为衬层厚度时，默认归入基体或外壳的`BODY`，不得推断为`LINING`。
11. 夹套产品只有一个壁厚且原文未明示为外层壁厚时，默认归入`INNER`；具体`ROLE`仍按该内层结构确定。
12. 异径管、大小头和异径短节只有一个壁厚且原文未明示位置时，默认归入`BODY + END_A`。

### 7.1 壁厚归属判定顺序

壁厚按以下优先级确定`SCOPE + ROLE`，高优先级覆盖低优先级：

1. 原文明示位置：主管、支管、内层、外层、衬层、`MAIN/BRANCH、INNER/OUTER、L/S、I/O`。
2. 原文明示完整壁厚组：例如`S40×S80、4mm×3mm`，按原文位置顺序对应。
3. 原文明示相同双壁厚：例如`S40×S40`，两个位置都标注`SCH40`，不得因值相同而合并。
4. 产品结构默认值：三通和四通单壁厚归`MAIN`；附加支管件单壁厚归`BRANCH`；异径件单壁厚归`END_A`；衬里产品未明示衬层时归`BODY`；夹套产品未明示外层时归`INNER`。
5. 普通单规格产品只有一个壁厚时归`BODY + SINGLE`。
6. 确认是壁厚但无法可靠判断位置时使用`UNKNOWN`或进入人工审核，不得随意复制到其他位置。

补充约束：

1. 同一位置同时明示Schedule和毫米壁厚时全部保留。
2. 同一`SCOPE + ROLE + type + value`不得重复。
3. `SINGLE`表示一个确定物理位置；同一`SINGLE`内出现两个同类型、不同值的尺寸或壁厚时，必须检查是否遗漏主管/支管、两端、夹套或衬层归属。
4. 同一`SCOPE`内，`SINGLE`原则上不得与`MAIN/BRANCH`或`END_A/END_B`并存；只有不同值确实描述同一物理位置的等价表达时，才允许保留在同一`ITEM`中。

## 8. LENGTH字段

`LENGTH`完全沿用现有数据集的字符串结构和标注口径。

```text
"LENGTH": "100MM"
```

没有长度时：

```text
"LENGTH": ""
```

固定规则：

1. 只提取产品自身长度。
2. 沿用现有长度单位换算和格式归一规则。
3. 技术说明、施工说明和无法确认用途的长度不提取。
4. 本次V2不改变任何既有长度标签规则。

## 9. PRESSURE字段

`PRESSURE`完全沿用现有数据集的字符串结构和标注口径。

```text
"PRESSURE": "CL300"
```

```text
"PRESSURE": "PN16"
```

没有压力等级时：

```text
"PRESSURE": ""
```

固定规则：

1. `CLASS、CL、#、LBS`继续按现有规则归一为`CL`。
2. `PN`继续按现有规则归一为`PN`。
3. 产品压力明示为`MPa`时按原文数值保留，单位统一大写为`MPA`，不换算为`PN`。例如`1.6MPa`标为`1.6MPA`。
4. `>=10MPa`等技术能力、试验压力或设计下限不是产品压力等级时不提取。
5. 除上述`MPA`口径纠正外，`LENGTH`及其他`PRESSURE`标签的结构和规则保持不变。

## 10. ITEM顺序

为了保证训练标签稳定，`ITEMS`按以下顺序输出：

1. 普通单规格产品：`BODY + SINGLE`。
2. 三通、四通和支管件：`MAIN -> BRANCH`。
3. 两端异径产品：`END_A -> END_B`。
4. 夹套产品：先`INNER`，再`OUTER`。
5. 夹套异径产品：`INNER/END_A -> INNER/END_B -> OUTER/END_A -> OUTER/END_B`。
6. 衬里产品：先`BODY`，再`LINING`。
7. `UNKNOWN`项始终放在最后。

## 11. 归属判定优先级

尺寸和壁厚的`SCOPE + ROLE`按以下优先级判断：

1. 明示位置词：`内管/外管、INNER/OUTER、主管/支管、MAIN/BRANCH、L/S、I/O`。
2. 完整规格组：`DN600x80、DN80x50 4mmx3mm、DN600x10mm/DN80xSCH40`。
3. 字段锚点：`DN、OD、Φ、NPS、SCH、THK、T、δ`。
4. 并行顺序：尺寸组和壁厚组均明确时按原文顺序对应。
5. 产品结构：支管结构使用`MAIN/BRANCH`，两端异径结构使用`END_A/END_B`。
6. 无法确认：使用`UNKNOWN`或进入人工审核。

更完整的规格组可以帮助判断前面重复表达的归属，但不得用于掩盖真实冲突。

## 12. 模型与代码职责边界

### 12.1 模型负责

- 提取原文明示的尺寸和壁厚。
- 为每个物理位置判断`SCOPE + ROLE`。
- 保持同一规格组内的对应关系。
- 保留同一位置的不同明示表达。
- 排除材质、标准、角度、半径、检测要求和技术说明中的无关数字。
- 保守处理无法确认的值。

### 12.2 代码负责

- `INCH -> DN`换算。
- `OD -> DN`按标准系列换算。
- 判断同一位置的多个明示值是否等价。
- 合并等价值并检测冲突值。
- 按业务规则选择最终编码值。
- 等径三通缺失支管尺寸补充。
- `END_A/END_B`转换为大端和小端。
- 最终材料代码拼接。

## 14. V1数据转换原则

现有V1结构：

```json
{
  "SIZE_ITEMS": [{"type": "DN", "value": "80"}],
  "LENGTH": "100MM",
  "THICKNESS_ITEMS": [{"type": "MM", "value": "4"}],
  "PRESSURE": "CL300"
}
```

转换为V2：

```json
{
  "ITEMS": [
    {
      "SCOPE": "BODY",
      "ROLE": "SINGLE",
      "SIZE": [{"type": "DN", "value": "80"}],
      "THICKNESS": [{"type": "MM", "value": "4"}]
    }
  ],
  "LENGTH": "100MM",
  "PRESSURE": "CL300"
}
```

转换时只重组尺寸与壁厚，并补充`SCOPE + ROLE`。`LENGTH`和`PRESSURE`必须原样保留。

以下情况不得未经审核直接转换：

- 尺寸数量和壁厚数量无法建立对应关系。
- 同时出现主管、支管、两端异径、夹套或衬层组合结构。
- 同时出现多个DN、OD、INCH和裸数字，且归属不明确。
- `SCH + MM`同时出现但无法确定是否属于同一位置。
- OCR造成`0/O、1/I/l、x/×`混淆。
- 旧标签已丢失原文中的尺寸或壁厚关系。

审核文件可以包含转换元数据，但这些字段不得进入训练输出：

```text
source_index
conversion_method
review_reason
original_output
suggested_output
```

## 15. 标注检查清单

1. 顶层是否只有`ITEMS、LENGTH、PRESSURE`。
2. 每个`ITEM`是否只有`SCOPE、ROLE、SIZE、THICKNESS`。
3. 相同`SCOPE + ROLE`是否被合并为一个`ITEM`。
4. 同一位置的不同明示值是否全部保留。
5. 完全相同且归属相同的重复值是否去重。
6. `SIZE`和`THICKNESS`是否按原文首次出现顺序排列。
7. `LENGTH`和`PRESSURE`是否仍为字符串。
8. 是否错误执行了OD或英寸到DN的换算。
9. 是否由模型补充了原文没有的支管尺寸。
10. `END_A/END_B`是否保持原文顺序。
11. `MFR'S STD`是否被错误标成壁厚。
12. 材质数字、标准年份、角度、半径和检测百分比是否被误提取。
13. 无法确认归属时是否使用`UNKNOWN`或进入审核。

## 16. 禁止事项

- 禁止增加候选层。
- 禁止把`SIZE`和`THICKNESS`重新拆回顶层数组。
- 禁止修改`LENGTH`和`PRESSURE`的数据结构。
- 禁止增加`RAW、INDEX、STRUCTURE_FEATURES`等非必要字段。
- 禁止在模型输出中生成最终材料代码。
- 禁止模型自行执行OD到DN或英寸到DN换算。
- 禁止为了得到唯一答案而删除不同的原文明示值。
- 禁止根据异径件名称自动判断`END_A`一定是大端。
- 禁止根据等径三通名称在模型层复制未明示的支管尺寸。
- 禁止把无法确认的裸数字强行绑定到最近字段。
