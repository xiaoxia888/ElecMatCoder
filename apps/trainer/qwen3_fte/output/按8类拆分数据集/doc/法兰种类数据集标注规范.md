# 法兰种类数据集标注规范 V2

> 状态：已固定  
> 生效日期：2026-08-06

## 1. 文档定位

本规范用于制作法兰种类模型的数据集，适用数据文件：

```text
apps/trainer/qwen3_fte/output/按8类拆分数据集/种类/法兰_train.json
apps/trainer/qwen3_fte/output/按8类拆分数据集/种类/法兰_val.json
```

本规范以当前训练集的真实结构和平台两阶段编码流程为基础，不沿用历史法兰标注草案。

系统职责分工：

- 一阶段识别法兰主体、连接形式和密封面，保留有业务意义的原文证据。
- 二阶段负责别名映射、编码优先级、未配置值过滤和最终编码。
- 不为了迁就当前编码表而让一阶段丢失 `SCRD`、`RTJ`、`FRJ` 等有效区别；但端部代码和历史别名需按本文的固定规则归一。

## 2. 固定输出结构

每条法兰样本统一输出以下结构，不增减字段：

```json
{
  "CATEGORY": "法兰",
  "TYPE": {
    "BODY": "",
    "CONN": [],
    "SEAL": []
  }
}
```

- `BODY`：法兰产品主体及其标准结构型式。
- `CONN`：法兰主体的连接或螺纹形式。
- `SEAL`：法兰密封面或表面形式。

尺寸、壁厚、压力、材质和规范不得写入 `TYPE`。

## 3. 总体原则

### 3.1 只依据原文明示信息

不得根据尺寸、压力等级、材质或产品标准推断法兰类型、连接形式或密封面：

- 只有 `ASME B16.5`，不能推断 `RF`、`RJ`、`WN` 或 `NPT`。
- 只有 `HG/T 20592`，不能推断 `WN`、`SO`、`THD` 或系列。
- 只有 `DN50` 或 `CL150`，不能判断公制螺纹或英制螺纹。
- `PTFE`、`衬胶`、`GALV` 属于材质、衬里或附加要求，不是密封面。

### 3.2 法兰结构型式例外

法兰与普通管件采用不同的BODY边界。`承插焊法兰、螺纹法兰、带颈对焊法兰、带颈平焊法兰、板式平焊法兰、松套法兰`是标准法兰结构型式，不得全部降级为`BODY=法兰`。

这项例外只适用于法兰体系。普通管件仍按“核心结构写入BODY、连接形式写入CONN”的规则标注，例如`NPT管帽 -> BODY=管帽、CONN=["NPT"]`，不能因为法兰保留`螺纹法兰`而创建`BODY=螺纹管帽`。

法兰保留当前业务标签体系：`WN/SO/PL/BW`只用于确定BODY，不写入`CONN`；`SW`除确定`BODY=承插焊法兰`外，还必须保留为`CONN=["SW"]`。螺纹法兰的具体制式同样写入`CONN`，用于区分`SCRD、NPT、FNPT、MNPT、THD`等编码路径。

| 原文法兰结构 | BODY | CONN |
|---|---|---|
| `SOCKET WELD FLANGE`、`SW FLANGE` | 承插焊法兰 | `["SW"]` |
| `THREADED/SCREWED/NPT FLANGE` | 螺纹法兰 | 保留原文最具体螺纹值 |
| `WN/WELD NECK FLANGE` | 带颈对焊法兰 | `[]` |
| `SO/SLIP-ON FLANGE` | 带颈平焊法兰 | `[]` |
| `PL/PLATE FLANGE` | 板式平焊法兰 | `[]` |

上表是法兰类别的闭合特例，不得用于普通管件。例如`SW ELBOW`必须标为`BODY=弯头、CONN=["SW"]`，不能仿照法兰生成“承插焊弯头”新`BODY`。

```text
SOCKET WELD FLANGE, RF
```

```json
{
  "BODY": "承插焊法兰",
  "CONN": ["SW"],
  "SEAL": ["RF"]
}
```

### 3.3 一阶段不输出最终编码

一阶段使用稳定标签，但不输出 `FN`、`FTH`、`FFN` 等最终种类编码：

- 原文 `SCRD` 标注为 `SCRD`，不提前改成 `NPT` 或 `FN`。
- 原文 `RTJ` 标注为 `RTJ`，不提前改成 `RJ`。
- 原文 `Female RJ` 标注为 `FRJ`，不压缩成 `RJ`。
- 原文 `Male RJ` 标注为 `MRJ`，不压缩成 `RJ`。
- `LMFE`、`FLRJ` 等端部或历史别名不作为独立密封面，分别归一为 `LM`、`RJ`。

## 4. CATEGORY 判定

法兰本体以及本项目约定由法兰结构承接的管道盲板，标注为 `CATEGORY=法兰`。

管道用插板、垫环、插板垫环组件和8字盲板在产品标准中属于管道盲板（Line Blanks），不是法兰本体；但其压力等级、密封面以及最终编码均使用当前法兰结构承接，因此也标注为 `CATEGORY=法兰`。这里的类别表示系统编码路由，不表示物理产品名称全部归一为法兰。

以下情况不属于法兰分类：

- `FLANGED PIPE`、法兰管：属于直管。
- 法兰弯头、法兰三通、法兰异径管：属于管件。
- 管子或管件描述中仅出现配套法兰材质、法兰标准、`RF`：仍按主体产品分类。
- `FLANGE: A105 GALV` 仅说明附件材质时，不能覆盖原文主体。
- 真正的阀门内部闸板、阀板或其他机械插板不是管道盲板，不得仅因出现“插板”而标为法兰。

## 5. BODY 标注

### 5.1 高频主体

| 原文产品词或明确语义 | `BODY` |
|---|---|
| `WN FLANGE`、`WELD NECK FLANGE`、带颈对焊法兰 | `带颈对焊法兰` |
| `SO FLANGE`、`SLIP-ON FLANGE`、带颈平焊法兰 | `带颈平焊法兰` |
| `BLIND FLANGE`、盲法兰、法兰盖 | `盲板法兰` |
| 普通 `FLANGE`，没有更具体产品词 | `法兰` |
| `SOCKET WELD FLANGE`、承插焊法兰 | `承插焊法兰` |
| `THREADED FLANGE`、`SCREWED FLANGE`、螺纹法兰 | `螺纹法兰` |
| `SPECTACLE BLIND`、`SPECTACLE BLANK`、`FIGURE-8 BLIND`、8字盲板 | `8字盲板` |
| `LAP JOINT FLANGE`、松套法兰 | `松套法兰` |
| `PLATE FLANGE`、`PAD FLANGE`、板式平焊法兰 | `板式平焊法兰` |
| 明确只写对焊法兰，但没有带颈语义 | `对焊法兰` |
| `PADDLE BLANK`、`PADDLE BLIND`、`SPADE`、明确的单插板 | `插板` |
| `PADDLE SPACER`、明确的单垫环 | `垫环` |
| `BLANK AND SPACER`、`PADDLE BLANK & SPACER`、插板与垫环成套供货 | `插板垫环组件` |

`BLIND FLANGE` 与 `SPECTACLE BLIND` 不得混淆：前者是 `盲板法兰`，后者是 `8字盲板`。

### 5.2 管道盲板产品族

管道盲板必须按实际结构分别标注，不能因为当前二阶段可能使用相同基础码，就把不同产品合并为同一个 `BODY`。

| 原文明示语义 | 标准 `BODY` | 说明 |
|---|---|---|
| 单独插板、单盲板、`PADDLE BLANK`、`PADDLE BLIND`、`SPADE` | `插板` | 实心单件，用于阻断管路 |
| 单独垫环、单环、`PADDLE SPACER` | `垫环` | 中空单件，用于保持管路连通 |
| `插板+垫环`、`插板/垫环`、`盲板,垫环`、`BLANK AND SPACER`、明确“成套供货” | `插板垫环组件` | 两个独立件组成的一套 |
| `8字盲板`、`SPECTACLE BLIND`、`FIGURE 8 BLIND` | `8字盲板` | 插板和垫环通过柄部连接的一体件 |
| `BLIND FLANGE`、`BL FLANGE`、法兰盖 | `盲板法兰` | 法兰产品，不属于管道盲板单件 |

判定规则：

- `PADDLE SPACER` 必须标为 `垫环`，不得标为 `插板`。
- `PADDLE BLANK` 和 `PADDLE BLIND` 标为 `插板`，不得标为 `8字盲板`。
- `BLANK AND SPACER` 表示两个独立件成套，标为 `插板垫环组件`，不得标为单独 `插板`。
- `SPECTACLE BLIND` 表示一体式8字结构，标为 `8字盲板`，不得标为 `插板垫环组件`。
- 原文只写“插板”时只标 `插板`，不得推断同时供应垫环。
- 原文只写“垫环”或 `PADDLE SPACER` 时只标 `垫环`，不得推断同时供应插板。
- 原文名称写“插板”，但同时明确写有“插板垫环成套供货”时，以完整产品语义为准，标为 `插板垫环组件`。
- `盲板垫环组件` 作为历史标签统一改为 `插板垫环组件`，避免与 `盲板法兰` 混淆。
- 同一条描述分别列出插板和垫环，且共享尺寸、压力、密封面并明确配套或成套时，才合并为 `插板垫环组件`；如果是两个独立明细项，不得强行合并。
- 普通法兰垫片、金属环垫、密封垫和 `GASKET/RING GASKET` 不是这里的 `垫环`。只有明确的管道盲板语境、`PADDLE SPACER` 或等价单垫环证据才标为 `垫环`。
- `With Blank` 只表示带有插板，不能单独证明还包含垫环；无法确认主体时进入人工审核。

产品标准可用于消除词义歧义，但不能凭标准号凭空补产品类型：

- `ASME B16.48`、`SH/T 3425`、`HG/T 21547` 可作为管道盲板语境证据。
- 原文出现“阀门插板”或“特殊管件插板”，同时具有上述管道盲板标准、压力等级、密封面和管径时，按管道盲板的实际结构标注，不受“阀门”或“特殊管件”前缀影响。
- 如果“阀门插板”明确是阀门内部零件，或缺少足以确认管道盲板的上下文，进入人工审核，不写入法兰训练集。

管道盲板的密封面按第7节写入 `SEAL`。例如 `PADDLE SPACER ... RF ... SERRATED FINISH` 应标为 `BODY=垫环`、`SEAL=["RF", "SERRATED"]`，不能因为产品不是法兰本体而丢弃密封面。

### 5.3 低频主体

以下标签只在原文明示对应产品时使用，不根据双尺寸、双壁厚或邻近词推断：

- `带颈平焊夹套法兰`
- `带颈对焊夹套法兰`
- `夹套盲法兰`
- `夹套法兰`
- `异径夹套法兰`
- `异径法兰`
- `异径板式法兰`
- `衬里法兰`
- `板式平焊松套法兰`
- `孔板法兰`
- `孔板对焊法兰`
- `固定法兰`

主体证据冲突且无法确认时，样本进入人工审核或从训练集移除。

## 6. CONN 标注

### 6.1 标签范围

`CONN`记录法兰主体的承插焊连接或螺纹制式。当前标准标签为：

```text
SW
THD
SCRD
NPT
FNPT
MNPT
FTE
MTE
GROOVED
```

`WN、SO、PL、BW`用于确定法兰标准结构型式，不写入`CONN`。`SW`是当前法兰体系的明确例外：`SOCKET WELD FLANGE`标为`BODY=承插焊法兰、CONN=["SW"]`；`WELD NECK FLANGE`仍标为`BODY=带颈对焊法兰、CONN=[]`。

### 6.2 螺纹法兰

螺纹制式必须保留到 `CONN`，不能只标 `BODY=螺纹法兰`，否则二阶段无法区分公制和英制编码。

| 原文证据 | 一阶段 `CONN` | 二阶段语义 |
|---|---|---|
| `SCREWED`、`SCRD` | `SCRD` | 按 `NPT` 体系编码 |
| 明确 `NPT` | `NPT` | 泛英制螺纹 |
| `THREAD`、`THREADED`、`THD` | `THD` | 泛螺纹/公制路径 |
| 只写中文“螺纹法兰”，无其他制式 | `THD` | 泛螺纹/公制路径 |
| `FNPT`、`FEMALE NPT` | `FNPT` | 英制内螺纹 |
| `MNPT`、`MALE NPT` | `MNPT` | 英制外螺纹 |
| `FTE`、`FEMALE THREAD` | `FTE` | 泛内螺纹 |
| `MTE`、`MALE THREAD` | `MTE` | 泛外螺纹 |

`SCRD -> NPT` 是本项目二阶段编码约定，不代表一阶段把 `SCRD` 改写为 `NPT`。

### 6.3 螺纹优先级

同一主体出现多种螺纹证据时，保留最具体标签：

```text
FNPT / MNPT > FTE / MTE > NPT / SCRD > THD
```

- `THD;NPT`：只标 `NPT`。
- `NPT;FNPT`：只标 `FNPT`。
- `FTE;FNPT`：只标 `FNPT`。
- `MTE;MNPT`：只标 `MNPT`。

### 6.4 辅助孔不作为主体连接

盲法兰中的 `Drilled & Tapped 1/2" NPT`、`Pressure Tap 1/2" NPT` 如果明确是取压孔、排放孔或辅助孔，不标为法兰主体 `CONN`。

## 7. SEAL 标注

### 7.1 允许输出的固定标签

```text
RF
FF
RJ
RTJ
FRJ
MRJ
MFM
LM
LF
MF
M
FM
T
G
TG
SERRATED
```

一阶段的 `SEAL` 只能输出上述标签，不得根据语义自行创造缩写。`SERRATED` 本质上是密封面加工要求，按当前平台结构暂时保留在 `SEAL`。

### 7.2 归一规则

| 原文证据 | `SEAL` |
|---|---|
| `RF`、Raised Face | `RF` |
| `FLRF` | 不提取 |
| `FF`、Flat Face | `FF` |
| `RJ`、Ring Joint | `RJ` |
| `RTJ` | `RTJ` |
| `Female RJ`、Female Ring-Joint | `FRJ` |
| `Male RJ`、Male Ring-Joint | `MRJ` |
| `FLRJ` | `RJ` |
| `MFM` | `MFM` |
| `MF`、明确“凹凸面”但未指明单侧 | `MF` |
| 明确单独凸面 `M`、Male Face | `M` |
| 明确单独凹面 `FM`、Female Face | `FM` |
| `LM` | `LM` |
| `LMFE` | `LM` |
| `LF` | `LF` |
| `T`、Tongue Face、榫面 | `T` |
| `G`、Groove Face、槽面 | `G` |
| `TG`、Tongue-Groove、榫槽面且未指明单侧 | `TG` |
| `SERRATED FINISH` | `SERRATED` |

特殊规则：

- `MFM` 仅在原文明确出现 `MFM` 时输出，不得由 `MF`、`M` 或 `FM` 推断。
- 原文只写“凹凸面”或 `MF` 时标为 `MF`；明确某一侧时分别标为 `M` 或 `FM`。
- `Female RJ` 必须标 `FRJ`，不能标成 `RJ`。
- `Male RJ` 必须标 `MRJ`，不能标成 `RJ`。
- `FRJ/MRJ` 只能由原文明确的 Female/Male Ring-Joint 触发，不得根据 `RJ/RTJ` 推断。
- `Female RJ(RTJ)` 以更具体的 Female 语义为准，标为 `FRJ`。
- `FRJ/MRJ` 主要用于原文明确的 ASME B16.48 Figure-8 Blank、Spectacle Blank 等管线盲板；普通法兰只出现 `RJ/RTJ` 时不做阴、阳面推断。
- `LMFE` 归一为 `LM`，`FLRJ` 归一为 `RJ`。
- `LFM`、`FLRF` 暂不作为正式枚举，原文只出现这些缩写时不写入 `SEAL`。
- `RTJ` 保留为 `RTJ`，二阶段可映射为 `RJ`。

### 7.3 枚举外密封面

原文出现枚举外的密封面、端部类型或历史缩写时，不得直接把未定义字符串写入 `SEAL`。已在本规范中定义别名的按固定规则归一，其余值不提取并进入人工审核。

例如：

```text
FWRF       -> 不提取
LFM        -> 不提取
FLRF       -> 不提取
LMFE       -> LM
FLRJ       -> RJ
Female RJ  -> FRJ
Male RJ    -> MRJ
```

`TYPE E SPIGOT` 等非密封面结构不得写入 `SEAL`；如果它也不是法兰主体连接方式，则不写入 `CONN`。

### 7.4 多个密封面属性

原文 `RF 125-250 AARH SERRATED FINISH` 标注为：

```json
"SEAL": ["RF", "SERRATED"]
```

数组按原文证据出现顺序排列，二阶段负责编码顺序。

```json
    "BODY": "8字盲板",
    "CONN": [],
    "SEAL": ["RF"]
  }
}
```

## 9. 脏数据处理

以下情况不直接改写标签：

- 同时出现互斥主体，如 `WN` 与 `SO`。
- 同时出现互斥连接，如 `SW` 与 `NPT`，且无法确认属于不同部件。
- 产品主体是管子或管件，但描述中混入法兰附件信息。
- 只写 `BLANK`、`SPACER`、插板或垫环，但上下文无法确认是管道盲板还是其他设备零件。
- 同一描述同时出现一体式 `SPECTACLE BLIND` 和成套式 `BLANK AND SPACER`，且无法判断主体。
- 辅助孔螺纹与法兰主体螺纹无法区分。
- 原文密封面缩写无法确认含义。

处理顺序：

1. 能由明确上下文区分不同部件时，按主体证据标注。
2. 无法区分时进入人工审核。
3. 仍无法确认时从训练集和验证集移除，不用代码后处理伪造答案。

## 10. 对比增强要求

增强数据优先使用真实项目骨架，重点构造最小差异对比。

### 10.1 螺纹对比

```text
SCREWED/SCRD -> SCRD
NPT           -> NPT
THREAD/THD    -> THD
FNPT          -> FNPT
MNPT          -> MNPT
FTE           -> FTE
MTE           -> MTE
```

### 10.2 密封面对比

```text
RJ / RTJ / FRJ / MRJ / FLRJ
LM / LMFE / LF
MF / M / FM / MFM
T / G / TG
RF / FLRF / FWRF / SERRATED
```

### 10.3 负样本

- `20/PTFE`、`PTFE LINED`：`PTFE` 不进入 `SEAL`。
- `Pressure Tap NPT`：辅助孔 `NPT` 不进入主体 `CONN`。
- 法兰标准但产品是管子或管件：`CATEGORY` 不得标为法兰。
- `PADDLE BLANK` 与 `PADDLE SPACER`：分别标为 `插板` 与 `垫环`，构造最小差异对比。
- `BLANK AND SPACER` 与 `SPECTACLE BLIND`：分别标为 `插板垫环组件` 与 `8字盲板`。
- `TYPE E SPIGOT`：不进入 `SEAL`。

禁止只批量替换词语而不检查语义，禁止生成现实中互相冲突的法兰组合。

## 11. 质量检查清单

每次合并训练集前至少检查：

- 所有样本均包含固定的 `BODY/CONN/SEAL` 三个字段。
- `CATEGORY` 必须为 `法兰`，`BODY` 不为空。
- `SCREWED/SCRD` 是否标为 `SCRD`。
- 泛 `THREAD/THD` 是否标为 `THD`。
- `FNPT/MNPT` 是否压掉泛 `NPT/THD`。
- `Female RJ` 是否误标为 `RJ`。
- `Male RJ` 是否误标为 `RJ`。
- `FRJ/MRJ` 是否在没有 Female/Male 明确证据时被推断出来。
- `LMFE` 是否已归一为 `LM`，`FLRJ` 是否已归一为 `RJ`。
- `LFM`、`FLRF`、`FWRF` 是否误进入 `SEAL`。
- 原文 `MF` 是否被错误扩展为 `MFM`。
- 榫面、槽面和未指明单侧的榫槽面是否分别标为 `T/G/TG`。
- `SEAL` 是否出现允许枚举之外的值。
- `PTFE`、材质、规范和压力是否误入 `SEAL`。
- `PADDLE SPACER` 是否误标为 `插板`。
- `BLANK AND SPACER` 或“成套供货”是否误标为单独 `插板`。
- `SPECTACLE BLIND` 是否误标为 `插板垫环组件`。
- 管道盲板是否错误进入管件数据集并丢失 `SEAL`。
- 辅助孔 `NPT` 是否误入主体 `CONN`。
- 相同输入是否存在不同输出。
- 训练集和验证集是否存在相同输入或相同骨架泄漏。

## 12. 二阶段衔接

一阶段标签与二阶段编码的关系由配置维护，不能反向污染训练标签：

```text
SCRD -> NPT语义 -> FN路径
NPT  -> FN路径
THD  -> FTH路径
FNPT -> FFN路径
RTJ  -> RJ编码
FLRJ -> RJ编码
LMFE -> LM编码
RF   -> 保留标签，但编码后缀为空
```

同一个结构化组合只能对应一个最终种类编码。例如 `螺纹法兰;SCRD` 不能同时配置到 `FN` 和 `FTH`。新增别名或编码时优先修改二阶段映射，不轻易改变一阶段已经稳定的标注语义。

`插板`、`垫环`、`插板垫环组件` 和 `8字盲板` 必须保持不同的一阶段标签。即使某些产品当前共享二阶段基础码，也应分别配置映射，不得反向把一阶段标签合并。
