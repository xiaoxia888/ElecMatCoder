# 材质规范 v3 标注说明

## 输出结构

```json
{
  "MATERIAL": [
    {
      "PART": "BODY",
      "VALUE": "ASTM A312 TP304L",
      "SPECIAL_REQ": []
    }
  ],
  "STANDARD": [
    {
      "BODY": "AB3619"
    }
  ]
}
```

## 核心规则

1. `VALUE` 表示一个物理部件完整、可直接用于二阶段编码的材质表达，不再拆分为材料标准、牌号和等级。
2. 同一个物理部件的双牌号、括号牌号和备选体系只标一条，例如 `S30408/S30403`、`2205(A182 F51)`、`ASTM A403 WP304/304L`。
3. 只有真实物理部件不同才拆分多条 `MATERIAL`，目前允许 `BODY`、`LINING`、`INNER_PIPE`、`OUTER_PIPE`、`FLANGE`。
4. `SPECIAL_REQ` 只保留参与材质编码的附加要求，例如 `NACE`、`GALVANIZED`、`ANTI-H2S`、`CE`、`3PE`、`4PE`、`PE`、`EP`。`4PE` 只有在“加强级外防腐、外涂、外覆、涂层”等强上下文中才提取，不能由连接形式 `PE` 推断。
5. 根级 `STANDARD` 仅保存产品、制造、尺寸或检验规范编码，不承载材质牌号。
6. v3 不包含 `MATERIAL_RELATION`，也不包含材质项内的 `STANDARD`、`GRADE`、`CLASS`。
7. 材质 `VALUE` 保留材料标准，例如 `ASTM A312 TP316`，不缩写成 `TP316`。
8. 只提取原文明示信息，不因产品名称推断产品规范，也不根据最终编码相同自动合并两套材料标准。
9. 同一物理部件同时出现两套材料标准且无法确定主标准时，删除该训练样本，不构造原文不存在的合并表达。
10. 材质体系或牌号前缀属于 `VALUE` 的有效语义，原文明示时必须保留。例如 `SUS 316`、`SUS F316L`、`SS316L`，不能简化为 `316`、`F316L`、`S316L`；原文没有前缀时也不得反向推断。
11. `TUBE-EP`、`SS31603-TUBE-EP`、`SS316L-EP(PN16)` 等孤立 `EP` 后缀无法区分涂层与电化学抛光，不写入 `SPECIAL_REQ`。只有原文明示“内 EP、EP 涂层、EP 防腐”等涂层语义时才提取 `EP`。
12. ASTM管件牌号中原文明示的制造等级后缀属于 `VALUE`，必须保留。A234、A403、A420中的`WPB-W`、`WPL6-W`、`WP304-WX`、`WP304/304L-WX`直接保留；分开写成`A234 WP11 ... Type W`或`A403 Grade WP304 ... Type WX`时分别归一为`ASTM A234 WP11-W`、`ASTM A403 WP304-WX`。不能仅因原文出现`WELDED`推断`-W/-WX`。

## 示例

`FLANGE WN, CL150, RF, S30408/S30403 NB/T 47010, SH/T 3406, GB/T 4334-C,S-40S;DN25`

```json
{
  "MATERIAL": [
    {
      "PART": "BODY",
      "VALUE": "S30408/S30403",
      "SPECIAL_REQ": []
    }
  ],
  "STANDARD": [
    {
      "BODY": "GBT4334C"
    },
    {
      "BODY": "SHT3406"
    },
    {
      "BODY": "NBT47010"
    }
  ]
}
```
