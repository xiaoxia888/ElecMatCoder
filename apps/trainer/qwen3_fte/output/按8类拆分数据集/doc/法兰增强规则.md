# 法兰增强规则

## 1. 增强目标

法兰增强的目的不是简单扩充样本数量，而是补齐低频 `BODY`、低频密封面、连接形式、端部形式，以及容易混淆的边界样本。

增强后样本必须保持六大标签一致，不能为了平衡 `TYPE` 而污染 `SIZE`、`THICKNESS`、`PRESSURE`、`MATERIAL`、`STANDARD`。

## 2. 数据来源

优先使用真实项目样本或真实样本骨架做最小改动。

允许增强的字段：

- `TYPE.BODY`
- `TYPE.CONN`
- `TYPE.SEAL`
- `TYPE.ENDS`

尺寸、壁厚、压力、材质、规范应尽量来自真实样本，不建议凭空组合。

不使用单一固定模板做大批量生成，避免模型学到假格式。

## 3. BODY 归一化

`WN`、`WELD NECK`、`WELDING NECK` 归为：

```json
{"BODY": "带颈对焊法兰"}
```

`SO`、`SLIP-ON`、`平焊法兰` 归为：

```json
{"BODY": "带颈平焊法兰"}
```

`SOCKET`、`SW`、`承插焊` 归为：

```json
{"BODY": "承插焊法兰", "CONN": ["SW"]}
```

`THD`、`THREAD`、`NPT`、`SCRD`、`螺纹` 归为：

```json
{"BODY": "螺纹法兰"}
```

`BLIND`、`盲法兰` 归为：

```json
{"BODY": "盲法兰"}
```

`法兰盖` 保留为：

```json
{"BODY": "法兰盖"}
```

`BLANK AND SPACER`、`BLANK&SPACER`、`插板+垫环`、`阀门插板` 归为：

```json
{"BODY": "插板"}
```

`SPECTACLE BLANK`、`SPECTACLE BLIND`、`FIGURE 8`、`FIGURE8`、`八字盲板` 归为：

```json
{"BODY": "8字盲板"}
```

`REDUCING FLANGE` 归为：

```json
{"BODY": "异径法兰"}
```

`ORIFICE FLANGE WELDING NECK` 归为：

```json
{"BODY": "孔板对焊法兰"}
```

`JACKET`、`夹套` 进入独立 `BODY`，例如：

```json
{"BODY": "带颈对焊夹套法兰"}
{"BODY": "带颈平焊夹套法兰"}
{"BODY": "夹套盲法兰"}
```

## 4. 互斥规则

`WN`、`SO`、`SW`、`THD`、`NPT` 属于互斥型式，不能在同一条样本中互相冲突。

以下样本直接删除，不改写：

```text
带颈对焊法兰 ... SO
平焊法兰 ... WN
对焊法兰 ... SO
法兰 ... SW，但 BODY 标为普通法兰
法兰 ... NPT，但 BODY 标为普通法兰
```

`承插焊法兰` 必须标注：

```json
{"BODY": "承插焊法兰", "CONN": ["SW"]}
```

`螺纹法兰` 可以标注：

```json
{"BODY": "螺纹法兰", "CONN": ["THD"]}
{"BODY": "螺纹法兰", "CONN": ["NPT"]}
```

`FNPT`、`MNPT` 放入 `ENDS`：

```json
{"ENDS": ["FNPT"]}
{"ENDS": ["MNPT"]}
```

出现 `FNPT` 或 `MNPT` 时，不强制自动补 `CONN=THD`。

## 5. 密封面规则

以下内容放入 `TYPE.SEAL`：

```text
RF
FF
RJ
RTJ
MFM
LM
LF
```

`RF` 虽然不参与部分二阶段编码，也应保留，保持一阶段结构完整。

`凹凸面`、`MF` 统一标为：

```json
{"SEAL": ["MFM"]}
```

`全平面` 标为：

```json
{"SEAL": ["LF"]}
```

密封面不得进入：

- `STANDARD.GRADE`
- `MATERIAL`
- `SIZE`
- `THICKNESS`
- `PRESSURE`

## 6. 规范规则

正常规范等级或系列可以进入 `STANDARD.GRADE`，例如：

```json
{"BODY": "HG/T20592", "GRADE": "A"}
{"BODY": "HG/T20592", "GRADE": "B"}
{"BODY": "NB/T47008", "GRADE": "II"}
```

`SH/T3406(...)` 这类括号型式不进入训练集，统一清成 `SH/T3406`：

```text
SH/T3406(WN) -> SH/T3406
SH/T3406(SO) -> SH/T3406
SH/T3406(BL) -> SH/T3406
SH/T3406(PL) -> SH/T3406
SH/T3406(B)  -> SH/T3406
```

对应输出中：

```json
{"BODY": "SH/T3406", "GRADE": ""}
```

`HG/T20592-2009B20` 这类粘连应清为：

```json
{"BODY": "HG/T20592", "GRADE": "B"}
```

其中 `20` 属于材质，不属于规范等级。

年份尾号不进入 `STANDARD.GRADE`：

```text
HG/T20615-09 -> HG/T20615
```

## 7. 合法组合

普通 `法兰` 可搭配常见密封面，但不主动补 `SW`、`THD`、`NPT`。

`承插焊法兰` 合法组合：

```json
{"BODY": "承插焊法兰", "CONN": ["SW"], "SEAL": ["RF"], "ENDS": []}
```

`螺纹法兰` 合法组合：

```json
{"BODY": "螺纹法兰", "CONN": ["THD"], "SEAL": ["RF"], "ENDS": []}
{"BODY": "螺纹法兰", "CONN": ["NPT"], "SEAL": ["RF"], "ENDS": []}
{"BODY": "螺纹法兰", "CONN": [], "SEAL": ["RF"], "ENDS": ["FNPT"]}
{"BODY": "螺纹法兰", "CONN": [], "SEAL": ["RF"], "ENDS": ["MNPT"]}
```

`盲法兰`、`法兰盖` 可有密封面。若原文明确有 NPT 孔或 tapped 结构，需要人工确认是否进入 `CONN` 或 `ENDS`。

`孔板对焊法兰` 中的 `Pressure Taps 1/2'' SW/NPT` 是取压孔形式，不作为法兰主体连接形式。

## 8. 增强数量原则

高频 `BODY` 不继续大量补充，例如：

- `带颈对焊法兰`
- `带颈平焊法兰`
- `法兰`
- `承插焊法兰`

低频 `BODY` 需要保底补充，例如：

- `板式平焊法兰`
- `插板`
- `松套法兰`
- `带颈对焊夹套法兰`
- `带颈平焊夹套法兰`
- `夹套盲法兰`
- `异径法兰`
- `孔板对焊法兰`

不能为了平衡做全组合笛卡尔积，尤其不能把所有密封面、连接、端部随意组合。

每个增强样本必须通过合法矩阵校验。

## 9. 审计规则

增强后必须检查：

- `input` 是否重复
- `TYPE.BODY / CONN / SEAL / ENDS` 是否互斥
- `STANDARD.GRADE` 是否混入 `WN/SO/SW/RF/RJ/THD/NPT`
- `input` 中是否残留 `SH/T3406(...)`
- 是否存在明显人工脏模板或不真实格式
- 是否存在 `WN`、`SO`、`SW`、`THD/NPT` 与 `BODY` 冲突

增强样本和删除样本都要单独导出，便于人工追溯。
